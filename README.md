# Futsal Rotation

Static app, no build, no network needed after first load.

- **Vercel:** import repo (framework "Other", no build command).
- **Offline on iPad:** open the Vercel URL once in Safari → Share → Add to Home Screen. It then works with no internet.
- **Download:** copy the folder (index.html + sortable.min.js) to a device and open index.html; works from local files too.
